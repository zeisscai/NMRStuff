# mnv

轻量化的核磁共振（NMR）数据处理与谱图排版工具。

## 这是什么

一个面向一维 NMR 数据的桌面应用：读取仪器原始数据，完成常规处理与分析，
输出可直接用于论文的谱图和峰表。

## 用什么编写

- **Rust**（2021 edition，MSRV 1.82）
- **egui / eframe** 原生 GUI
- Cargo workspace 组织，按「模型 / 格式 / 处理 / 分析 / 渲染 / 报告 / 应用 / 命令行」分层，
  核心逻辑与界面解耦，同一套代码可同时供 GUI 与命令行使用

## 有什么功能

| 环节 | 能力 |
| --- | --- |
| 数据导入 | Bruker TopSpin、JCAMP-DX、CSV，以及内置示例数据 |
| 谱处理 | 窗函数、零填充、FFT、相位校正、基线校正、定标 |
| 谱分析 | 标峰、积分、多重峰识别与耦合常数解算 |
| 出图与报告 | 谱图排版与标注、JACS / Angew / RSC 风格的文本报告 |
| 命令行 | 无 GUI 的处理入口，可批量化调用 |

## 项目状态

**早期框架开发阶段（v0.1 原型）。**

当前重点是把整体结构、数据模型与处理链路搭稳，而非功能完备度；
接口仍在调整，功能覆盖与稳定性都不完整，尚不适合作为日常生产工具使用。

本仓库用于记录开发进程，**暂不接受外部贡献、不提供技术支持、不发布二进制版本**。

## 构建

需要 Rust 1.82 或更高版本：

```bash
cargo build --release
cargo run --release          # 启动图形界面
cargo run -p mnv-cli -- --help   # 命令行用法
```
